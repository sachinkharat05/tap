⚙️ Getting Started

Follow these steps to get started:

1. 📥 Clone or download this repository to your local machine.
2. 💻 Open your preferred SQL editor or database management tool.
3. 🗄️ Open and execute "Create database.sql".
4. 📊 After successful database creation, execute "Insert queries.sql".
5. 📝 Explore the "mcq test/" folder to access the available MCQ test materials.

⚠️ Important Notes

- Execute the database creation script before running the insert queries.
- Verify the SQL syntax and database configuration before execution.
- Check the SQL scripts for database names, table definitions, and other implementation details.

🛠️ Prerequisites

- Database Management System (DBMS)
- SQL Editor or Database Client
- Basic Knowledge of SQL
- Understanding of Database Concepts
